Софт для создания туннелей к камере Dahua (по серийному номеру) с форвардингом любого порта на localhost через облачный протокол Dahua HTTP P2P. По сути — улучшенная версия DH-P2P.

## Улучшения 

- Поддерживает форвардинг **нескольких портов сразу**
- Поддерживает многопоточность
- Строит стабильные туннели к камере

## Сборка

```sh
git clone [https://github.com/undervolter/dh-fwd](https://github.com/undervolter/dh-fwd)
cd dh-fwd
go build .

```

## Как пользоваться

```sh
./dh-fwd [options] <serial>

```

**Или:**

```sh
./dh-fwd <serial> [options]

```

> [!NOTE]
> Dahua может отклонять запросы, если у вас рассинхронизировано системное время.

## Не проверено

* **Type 1 Auth**: восстановлен принцип работы через ревёрс SmartPSS Lite, не проверялся

### Флаги

| Флаг | Короткий | Что делает |
| --- | --- | --- |
| `--debug` | `-d` | Режим отладки |
| `--log-retries` | `-lr` | Лог повторных попыток с таймштампом |
| `--port` | `-p` | Порт (см. ниже) |
| `--threads` | `-mt` | Количество потоков (по умолчанию 3) |
| `--pool` | `-` | Количество реалмов в пуле (по умолчанию 50) |
| `--smart-pss` | `-2` | Форвардит порты 80 и 37777 одновременно |

`--help` / `-h` выводит список всех доступных команд.

### Как указывать порты (`--port`)

Есть 2 типа портов: локальный (который мы слушаем) и внешний (порт на самой камере).

Формат: `локальный:внешний`.

Если указан только один порт (например: `-p 80`) — внешний порт 80 открывается на **любом** свободном локальном порте системы.

Примеры ввода:

* `-p 5080,5081,5082:80,81,82` — явные пары «локал:камера», один к одному;
* `-p 8080,8081,8082:80` — несколько локальных портов на один внешний;
* `-p 80-85` — диапазон портов;
* `0:81` — порт `0` означает «любой свободный в системе»;
* если порт не указан вовсе — открывается порт 554 по умолчанию.

Локальные порты биндятся на `127.0.0.1` (`localhost`).

> [!WARNING]
> Если запускать софт без флага -p или биндить порты `<1024` без привилегий суперпользователя (`sudo` / администратор), возникнет ошибка:
> ```sh
> Tunnel failed, reason - no listeners available for tunnel
> 
> ```
> 
> 

### Режимы работы

**Single** — форвардит только 1 порт:

```sh
./dh-fwd SN -p 5080:80

```

**Multi** — форвардит несколько портов одновременно. Срабатывает автоматически, если передано несколько портов или включен многопоточный режим:

```sh
./dh-fwd SN -p 5080,5081:80,81 -mt 4

```

```text
Opening 2 ports on SN | Threads: 4
[..] Opening SN:80 | Connecting...
[OK] Obtained SN:80 -> 127.0.0.1:5080
[OK] Obtained SN:81 -> 127.0.0.1:5081
Obtained 2 ports on SN:80,81 | localhost:5080,5081

```

## Что такое Dahua P2P?

Это проприетарный облачный протокол Dahua, используемый для соединения с устройствами через интернет, даже если камера находится за несколькими NAT.

Пайплайн работы:

1. Клиент (SmartPSS или `dh-fwd`) шлёт запрос на мастер-сервер авторизации
2. Получает адрес промежуточного сервера
3. Инициирует канал связи и проводит процедуру пробива NAT (STUN/ICE)
4. PROFIT

> [!IMPORTANT]
> До **2024 года** P2P-сервера Dahua устанавливали соединение *без аутентификации*. После всей шумихи с дырявостью протокола устройства выпущенные после 2024.07 теперь требуют аутентификацию.
