	Софт для создания туннелей к камере Dahua (по серийнику) и форвардит любой порт на localhost через облачный протокол Dahua HTTP P2P. По сути — улучшенная версия DH-P2P.

	## Улучшения 

	- Поддерживает форвардинг **нескольких портов сразу**
	- Поддерживает многопоточность
	- Строит стабильные туннели к камере

	## Сборка

	```sh
	git clone https://github.com/undervolter/dh-fwd
	cd dh-fwd
	go build .
	```

	## Как пользоваться

	```
	./dh-fwd [options] <serial>
	```
	**Или:**
	```
	./dh-fwd <serial> [options]
	```

	> [!NOTE]
	>  Dahua может отклонять запросы если у вас десинхронизация времени

	## Не проверено
	-  Поддержка входа к камере которая требует Type 1 Auth

	### Флаги

	| Флаг | Короткий | Что делает |
	|------|----------|----------|
	| `--debug` | `-d` | дебаг |
	| `--log-retries` | `-lr` | лог ретраев с таймштампом |
	| `--port` | `-p` | порт, см. ниже |
	| `--threads` | `-mt` | кол-во потоков (по умолчанию 3) |
	| `--pool` | `-` | количество реалмов в пуле (по умолчанию 50) |
	| `--smart-pss` | `-2` | форвардит порты 80 и 37777 одновременно |

	`--help`/`-h` выводит список команд.

	### Как указывать порты (`--port`)

	Есть 2 порта - локальный (который мы будем слушать) и внешний (который камера нам отдает).
	Слева - локальный, справа - внешний.
	Если указан только один порт (пример: -p 80) - открывается порт 80 на ЛЮБОМ свободном порте.

	Примеры ввода:

	- `-p 5080,5081,5082:80,81,82` — явные пары «локал:камера», один к одному;
	- `-p 8080,8081,8082:80` — несколько локальных портов на один внешний;
	- `-p 80-85` — диапазон портов;
	- `0:81` — порт `0` означает «любой свободный в системе»;
	- если порт не указан — открывается порт 554 по дефолту.

	Локальные порты открываются на `localhost`.

	> [!WARNING]
	> Если вы запускаете софт без флага `-p` или указываете слушаемый порт `<1024` и программа не запущена с `sudo`, возможна ошибка:
	> ```sh
	> Tunnel failed, reason - no listeners available for tunnel
	> ```
	### Режимы работы

	**Single** — форвардит только 1 порт 
	```sh
	./dh-fwd SN -p 5080:80
	```

	**Multi** — форвардит несколько портов одновременно. Срабатывает автоматически, если портов несколько, или если включена многопоточность
	```sh
	./dh-fwd SN -p 5080,5081:80,81 -mt 4
	```
	```
	Opening 2 ports on SN | Threads: 3
	[..] Opening SN:80 | Connecting...
	[OK] Obtained SN:80 -> 127.0.0.1:5080
	[OK] Obtained SN:81 -> 127.0.0.1:5081
	Obtained 2 ports on SN:80,81 | localhost:5080,5081
	```

	## Что такое Dahua P2P?

	Это проприетарный облачный протокол Dahua, который используется для соединения с камерами по облаку, даже если камера находится хоть за 3мя NAT. Работает это +- так: клиент (SmartPSS, или dh-fwd) отправляет запрос на главный сервер -> получает промежуточный сервер -> создаёт канал связи -> пытается пробить NAT (если он симметричный) -> поднимаем туннель -> PROFIT.

	> [!IMPORTANT]
	> До **2025 года** P2P-сервера Dahua поднимали туннель *без аутентификации*. Устройства, выпущенные **после второй половины 2024 года**, запрашивают аутентификацию **до** установки туннеля.
